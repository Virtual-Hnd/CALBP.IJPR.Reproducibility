# IJPR DOE Experiments — Audrey Competitive

This repository is a cleaned export of the CALBP DOE campaign prepared for running the experiments on multiple machines.

## Included

- `MILP_Audrey.py`: main solver used for the DOE campaign
- `MILP_V1.py`: kept as legacy reference
- `calbp/`: data handling, DOE generation, metrics
- `scripts/run_doe_L9.py`: main experiment launcher
- `scripts/collect_run_info.py`: flatten all `run_info.json` files into one CSV
- `scripts/dashboard.py`: dashboard for browsing results
- `benchmark_selection.csv`: exact 14 Scholl + 14 Otto instances embedded in this repo

## Benchmark Scope

The benchmark has already been reduced to the curated subset used for the paper:

- 14 Scholl instances
- 14 Otto `n=20` instances
- 9 L9 configurations
- total = `252` runs

The DOE uses:

- uniform sampling once per configuration inside each interval-valued level
- deterministic configuration-specific seeds
- Audrey competitive MILP profile: `C2a + C4wy`, with `C5bc` disabled

## System Requirements

Python packages:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

External solver:

- IBM ILOG CPLEX must be installed on the machine
- either the `cplex` command must be available on `PATH`, or set one of:
  `CPLEX_CMD=/absolute/path/to/cplex`
  `CPLEX_BIN=/absolute/path/to/cplex/bin/arm64_osx`
  `CPLEX_STUDIO_DIR=/absolute/path/to/CPLEX_Studio2212`

## Quick Validation

Run one smoke test before launching the full campaign:

```bash
python3 scripts/run_doe_L9.py --smoke --time-limit 30
```

## Launching on Two Mac Mini Machines

The simplest split is by configuration. This avoids overlap in `(instance, config)` pairs and makes merging trivial.

Mac Mini A:

```bash
python3 scripts/run_doe_L9.py --configs c01 c03 c05 c07 c09 --time-limit 300 --resume
```

Mac Mini B:

```bash
python3 scripts/run_doe_L9.py --configs c02 c04 c06 c08 --time-limit 300 --resume
```

Each machine will produce its own `results_doe_L9/` tree.

## Merging Results

After both machines finish, gather the `results_doe_L9/solutions/` folders into one copy of the repository, then rebuild the flat summary CSV:

```bash
python3 scripts/collect_run_info.py --roots results_doe_L9 --output results_doe_L9/run_info_flat.csv
```

If you also want the campaign-level master CSV generated by the DOE launcher, keep the `doe_results.csv` from one machine as a base and regenerate consolidated summaries from the `run_info.json` files.

## Notes

- Results are not versioned in this cleaned repository.
- The old archives and exploratory comparison outputs were intentionally excluded.
- The benchmark file list is frozen in `scripts/run_doe_L9.py` and duplicated in `benchmark_selection.csv` for traceability.
